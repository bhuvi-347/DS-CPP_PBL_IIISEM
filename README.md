# DS-CPP_PBL_IIISEM
## Smart Campus Lost and Found Matching System

### Project Overview:

The Smart Campus Lost and Found Matching System is a console-based application designed to help students and staff report, search, and match lost and found items within the college campus.

Currently, lost and found items are mainly reported through WhatsApp groups, notice boards, or by asking around. This can make it difficult to track and search for items.

The proposed system aims to provide a centralized and organized way to manage lost and found items.

### Objectives:

- Report lost and found items.
- Search for lost and found items.
- Find possible matches between lost and found items.
- Update the status of items when they are recovered.
- Improve the efficiency of the campus lost and found process.

### Concepts Used:

#### Data Structures in C:
- Linked Lists
- Stacks
- Queues
- Searching
- Sorting

#### Object-Oriented Programming in C++:
- Classes
- Objects
- Encapsulation
- Inheritance

### Development Approach:

The project will initially be developed as a console-based application using C and C++.

File handling will be used to store records, while Data Structures and OOP concepts will be applied to implement the system functionality.
